# Meenakshi Art Work

Premium, conversion-focused website for Meenakshi Oil Painting in Saharanpur.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Included

- Next.js 15 App Router and TypeScript
- Tailwind CSS design foundation
- Framer Motion scroll reveals
- Home, Academy, Gallery, Custom Orders and Contact routes
- Context-specific WhatsApp conversion links
- Local SEO metadata and Google Maps link
- Responsive desktop and mobile navigation
- Error tracking with Sentry
- Performance monitoring with Vercel Analytics
- Business analytics with Google Analytics 4

The founder portrait and gallery photography are intentional placeholders. Replace them with original studio photographs before launch.
